## Dataset V2 — Pre-training Benchmark
The dataset contains controlled synthetic material relationships, counterfactual technical variants, hard negatives, evidence labels, and a public real-material development subset. Synthetic ground truth is used for supervised evaluation, while real public records are used for domain grounding and development testing. Leakage checks and dataset validation are included.
